# 검증 기록

검증일: 2026-10-11. Windows / RTX 5060 Ti 16 GB / PyTorch 2.8.0+cu128 / Python 3.13 / Edge headless.

## 제공된 4장

| 이미지 | 해상도 | 등록 레이어 | 전경 알파 합 오차 | 미배정 전경 픽셀 | 처리 시간* |
| --- | --- | --- | --- | --- | --- |
| 01 정면 전신 | 960×1182 | 7 | 0 | 0 | 10.63초 |
| 02 앉은 자세 | 1082×960 | 6 | 0 | 0 | 2.68초 |
| 03 잘린 전신 | 959×1001 | 7 | 0 | 0 | 2.12초 |
| 04 상반신 | 600×600 | 6 | 0 | 0 | 2.39초 |

* `processing_seconds`는 원본 읽기부터 부위 계산까지이며 PNG 저장 시간은 제외한다. 01은 프로세스 최초 모델 로드를 포함한다. 같은 하드웨어에서의 한 번의 실행 결과로, 일반 성능 보장이 아니다.

등록 샘플은 AnimeSeg + Depth Anything V2 Small + 샘플별 경계 가이드를 사용한다. 각 레이어 PNG를 다시 읽어 알파 합과 전경 RGB가 cutout/source와 일치하는지 확인했다. 03/04는 하단에 실제 그림이 닿아 있는 상태를 보존했다. 04의 원본 서명도 결과에 남아 있다.

이 값은 정답 마스크와 비교한 정확도가 아니다. 원본 RGB 보존과 분할의 완전성에 대한 검사다.

## 무가이드 자동 분절 별도 평가

`scripts/evaluate_auto.py`는 제공 4장에 SemanticSam을 적용하되 등록된 수동 가이드를 읽지 않는다. 결과는 `test-results/automatic/`에 별도로 저장한다.

| 이미지 | 자동 부위 수 | 의미 분절 시간 | 관찰 |
| --- | --- | --- | --- |
| 01 | 6 | 7.801초 (최초 로드 포함) | 머리 윗부분 일부가 얼굴로 오분류됨 |
| 02 | 6 | 0.459초 | 겹친 다리·옷·피부 경계에서 혼동 발생 |
| 03 | 8 | 0.434초 | 긴 뒷머리 일부를 의상으로 분류함 |

따라서 SemanticSam의 19클래스 출력만으로 모든 구도에서 정확한 부위 분리가 보장된다고 판단하지 않았다. 등록 4장은 별도 가이드로 이 오류를 보정했다. 기본 액자는 독립 평면과 종이 보조층을 사용하며 원본에 없는 신체를 생성하지 않는다.

## Windows 위젯 EXE 검증

- Electron 44.7.0과 .NET Framework 런처를 포함한 Windows x64 EXE를 브라우저 버튼으로 실제 내려받았다. 샘플 01 파일 크기는 156.9 MiB였다.
- 테스트에서 간격·테마·움직임·숨김을 바꾸고 저장 버튼을 누르지 않은 채 내려받았다. EXE 내부 스냅샷과 실행된 뷰어가 현재 변경값을 포함하고, 기존 서버 설정은 바꾸지 않았음을 확인했다.
- 스튜디오 서버를 종료하고 연결 실패를 확인한 뒤 EXE를 실행했다. 액자·이미지·보조층이 렌더링되고, 로컬 서버 없이 재실행도 성공했다. 테스트가 끝난 뒤 서버는 다시 시작했다.
- 실제 Windows 커서를 위젯 밖에서 이동해 액자 각도 변화 확인. 자동 회전, 둘 다 끈 정지 상태, 240×320 / 320×420 / 440×570 크기 변경 확인. 크기를 바꿔도 오른쪽·아래 모서리를 유지했다.
- 재실행 시 크기·회전 옵션과 창 위치가 유지되고, 나머지 액자 스냅샷은 동일했다. 렌더러 Node 접근이 차단되고, 위젯 IPC로 간격 같은 액자 설정을 바꾸려 하면 거부됨을 확인했다.
- Python 22개 검사 통과: 위젯 패키징 3개는 PSD 원본 순서, 사용자 지정 순서, 배경 파일 포함, 잘못된 설정/외부 경로/오래된 이미지 revision 거부, 다운로드 후 임시 EXE 삭제를 검사한다.
- Node 위젯 옵션 검사 3개 통과: 옵션 허용 범위, 오른쪽 아래 배치, 크기 변경, 모니터 제거·음수 좌표·작은 화면에서 화면 안으로 보정하는 계산을 검사한다. 여러 실제 모니터와 다른 DPI의 조합은 별도 장비에서 실측하지 않았다.
- 기존 브라우저 검사와 편집기 검사도 통과했다. 사용자 이미지 6장과 설정은 보존했다.
