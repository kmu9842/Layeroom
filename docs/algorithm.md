# 구현 알고리즘

## 1. 좌표·알파

입력에 EXIF 회전을 적용하고 긴 변을 최대 1600px로 제한한다. 원본 이미지의 유효 alpha가 있으면 그대로 쓴다. 없으면 AnimeSeg 모델에 1024 정사각형 letterbox RGB [0,1] 텐서를 입력한다. 모델 출력에서 letterbox를 제거하고 입력 좌표로 보간한다.

단색 배경 판정은 외곽 픽셀의 중앙색으로부터 RGB 거리 12 이내의 비율이 0.58보다 큰지 검사한다. 단색이면 채널 최대 차이 12 이하인 픽셀의 4연결 성분 중 이미지 외곽과 연결된 성분을 배경으로 제거한다. 이 보정은 선으로 둘러싸인 흰 머리 내부를 배경으로 취급하지 않는다. 다만 선이 끊기거나 실제로 배경과 연결된 흰색 영역은 오판할 수 있다.

신경망 출력의 높은 확신 영역과 근접 색상 경계를 결합하고 alpha를 0~255로 저장한다. 별도의 생성형 경계 복원은 수행하지 않는다. 이 단계는 일반적인 trimap 기반 고정밀 매팅의 완전한 대체가 아니다.

## 2. 부위 분절

일반 업로드는 See-through 공개 19클래스 SemanticSam을 사용한다. 공식 코드를 고정 커밋에서 읽고 `weights_only=True`로 체크포인트를 로드한다. CUDA에서는 BF16 autocast로 추론한다. 모델을 한 번 로드한 뒤 캐시한다.

클래스 logit에서 argmax를 취한다. 눈·코·입을 얼굴에 병합하고, 매우 작은 클래스는 인접 유효 부위에 할당한다. alpha가 0인 곳은 배경, alpha가 양수인 곳은 정확히 하나의 부위 ID가 된다. 모델 파일이 없을 때만 깊이 분위수 5구간을 대체 사용하며 이름을 `깊이 영역`으로 표시한다. 의미 분절 모델 실행 오류를 의미 분절 성공으로 바꾸지 않는다.

제공 4장은 별도 경계 가이드를 쓴다. 다각형으로 초깃값 L을 만든 뒤 각 영역을 2~6px 침식한 내부를 seed로 잡는다. Lab 영상 각 채널의 Sobel gradient 크기를 경계 비용으로 사용하고, alpha 내부에서 marker watershed를 적용한다. seed 바깥의 좁은 경계대만 선화에 맞춰 이동한다. 이 방식은 단순 bounding box 컷보다 낫지만 수동 가이드의 잘못된 의미 자체를 고치지는 못한다.

## 3. 깊이 지도 미리보기

Depth Anything V2 Small이 예측하는 상대 inverse depth D를 foreground의 3~97 백분위로 정규화한다.

`D_norm = clip((D - P3) / (P97 - P3), 0, 1)`

부위별 지정 깊이를 S, 입력의 긴 변을 M이라고 두고:

`Z = GaussianBlur(0.78 S + 0.22 D_norm, sigma=M/95)`

외부 영역은 가장 가까운 foreground 깊이로 확장한 뒤 blur한다. 배경의 0이 캐릭터 실루엣 안으로 스며들어 가장자리가 꺼지는 것을 방지한다. 이 확장은 색상이나 가려진 신체를 생성하지 않는다.

0.78/0.22는 본 앱의 보수적인 시각 설계값이다. 논문에서 보편 최적값으로 검증된 수치가 아니다. 이미지 밝기나 의상 무늬로 생기는 깊이 변동을 줄이고 사용자가 정한 부위 앞뒤 관계를 우선한다.

## 4. 렌더링

기본 액자는 Three.js 직교 카메라, 깊이를 가진 액자 벽과 앞·뒤 테두리, 뒷판, 독립된 레이어 평면으로 구성한다. 앞에서부터 순서 i의 위치는 `z_i = -i × gap`이다. 최전면은 0, 마지막 평면은 액자 내부의 가장 깊은 곳이다. 단일 레이어 액자의 벽은 최소 0.12 깊이를 가진다. 이미지 재질에는 조명을 곱하지 않는다.

기본 간격은 0.06, 초기 yaw는 −0.1 rad, 조절 가능한 회전 한도는 15~65°이고 기본값은 40°다. 간격을 좁게 두어 부위의 연결감을 유지한다. 넓은 간격이나 큰 회전에서는 원본에 가려진 영역이 비어 보일 수 있다. 머리·얼굴 우선 정렬은 적용하지 않는다. 사용자 정렬은 앞→뒤 ID 목록으로 저장한다.

분리 레이어 보기에서만 `max(0.22, gap×2)` 간격으로 펼쳐 검사한다. 목록은 dnd-kit Sortable의 드래그 핸들, 이동 미리보기, 스크롤, 마우스·터치·키보드 센서를 사용한다. 참고: https://dndkit.com/legacy/presets/sortable/overview/ 및 https://dndkit.com/legacy/presets/sortable/use-sortable/ .

움직임을 체크한 레이어만 X/Y의 작은 주기 운동을 한다. 회전 각속도와 카드 전환에서 생기는 작은 충격은 감쇠 스프링으로 계산하며, 위치를 X ±0.035 / Y ±0.025 이내로 제한한다. 체크를 해제한 레이어는 고정한다. 움직임은 Z 위치를 바꾸지 않는다. OS의 모션 감소 설정도 따른다.

각 조각의 윤곽을 액자 안쪽까지 내려 종이 보조층의 옆면 메시를 만든다. 외곽과 내부 구멍을 모두 처리하며, 앞면에서 읽은 색과 0.04 world unit 간격의 종이 단면 띠를 표시한다. 띠에는 화면 미분 기반 안티앨리어싱을 적용한다. 동일한 평면을 수십 장 겹쳐 그리는 대신 닫힌 윤곽의 옆면으로 두께를 표시하여 빈 공간과 렌더링 비용을 줄인다. 보조층은 해당 레이어의 숨김·정렬·움직임을 따른다. 분리 검사 모드에서는 보조층을 숨긴다.

## 4.1 절단 경계 표시 보정

부위 마스크의 내부/외부 Euclidean distance 차이를 signed distance로 만들고 해상도에 따라 sigma 0.8~1.8로 평활화한다. 얇은 가닥은 이웃의 최대 두께로 구별해 소실을 막는다. 경계 1.15px 폭에 smoothstep coverage를 주고 원래 전경 알파를 곱한다. 공유 경계에는 약 0.42px의 작은 겹침을 허용해 이음새의 투명한 틈을 줄인다. 캔버스 가장자리는 replicate padding으로 처리한다.

완전 투명 픽셀의 RGB를 해당 레이어의 가까운 경계색으로 채워 GPU 필터링의 흰 테두리를 줄인다. 보정본은 `layer-N-smooth.png`로 저장하며 원래 label·alpha·부위 PNG는 덮어쓰지 않는다. PSD에는 이 보정을 적용하지 않는다.

## 4.2 PSD

psd-tools 1.24의 원본 스택 순서를 따라 표시 평면을 구성한다. API의 아래→위 순서를 UI에서 위→아래로 반전할 뿐 부위 이름으로 재정렬하지 않는다. 숨긴 레이어도 추출하고 초기 표시만 끈다. 각 레이어의 원본 캔버스 위치, 마스크, 투명도를 반영한다. 그룹 효과나 클리핑으로 결합된 묶음은 하나의 평면으로 합성하고 원본 파일은 그대로 저장한다. 모델 추론은 호출하지 않는다. 문서 전체 조정/특수 혼합은 한계가 있으며 UI에 안내한다.

공식 자료: https://psd-tools.readthedocs.io/en/latest/usage.html 및 https://psd-tools.readthedocs.io/en/latest/reference/psd_tools.api.layers.html .

## 5. 불변 조건

`A_k(p) = A(p)` if `L(p)=k`, otherwise 0.

원본 분절 PNG에서는 각 pixel p가 하나의 L만 가지므로 `sum_k A_k(p) = A(p)`를 강제한다. 각 레이어의 RGB는 원본 RGB의 복사본이다. 실제 저장된 원본 PNG를 다시 읽어 이 합과 전경 RGB 일치를 테스트한다. 표시 보정 PNG는 부드러운 투명 경계와 작은 겹침을 가지므로 이 불변 조건의 대상이 아니다. PSD도 원래부터 겹치는 레이어가 있으므로 합 분할 조건을 적용하지 않는다.

이는 분절의 의미 정확도, 안티앨리어싱 품질, alpha 정답도를 검증하지 않는다. 그 수치를 산출하려면 별도의 정답 라벨과 검수 표본이 필요하다.

## 6. 편집·저장

브러시는 원본 RGB를 바꾸지 않고 alpha와 부위 label만 수정한다. 깊이 slider는 부위별 S를 수정한다. 저장하면 깊이와 PNG를 다시 계산한다. metadata revision이 다른 수정 요청은 409로 거절한다. 업로드는 별도 작업 대기열에서 한 번에 하나씩 추론해 모델 메모리 경쟁을 막는다.

새 이미지의 자동 mask가 틀리면 부위 지정 brush, 배경 제거 brush, 원화 복원 brush로 고칠 수 있다. 브러시 기반 6단계 undo를 제공한다.
