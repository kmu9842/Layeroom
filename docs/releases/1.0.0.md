Layeroom 1.0.0 — Windows x64 포터블 배포판

- Z축 간격: 0–0.1, 기본 0.025, 변경 단위 0.005.
- 회전·전환 관성 제거. 새 작품의 레이어 움직임은 기본 비활성화.
- 경계 수정 버튼 확대. 편집기에서 이름·표시 색상을 지정해 레이어 추가, 칠하기, 저장·재편집 지원.
- PSD 원본 순서 유지, 드래그 정렬, 종이 보조층, 커스텀 액자·배경, 독립 위젯 EXE 출력.
- Windows 탐색기로 설치 위치 선택. 모델은 처리할 때만 로드하고 완료·실패 후 해제.

`Layeroom-Windows-x64.zip`을 풀고 `Layeroom.exe`를 실행하세요. ZIP에는 EXE와 사용·사양 가이드 PNG 10장만 들어 있습니다. 안내용 캐릭터는 가이드 화면에만 사용하며 컬렉션은 비어 있습니다. 모델·개발 환경·리서치 노트·기존 작품은 포함하지 않습니다.

첫 실행에서 기본 환경을 설치합니다. 자동 분절용 CPU 또는 NVIDIA GPU 구성요소와 위젯 출력 기능은 선택 설치입니다. 설치 파일·모델·작품은 선택한 폴더의 `_internal`에 저장됩니다.

`Layeroom-Guides.zip`은 동일한 가이드 이미지 묶음이며, `Layeroom-Windows-x64.zip.sha256`으로 앱 ZIP을 검증할 수 있습니다.

검증: Python 51개, 페인팅·위젯 옵션 7개 통과. 실제 브라우저에서 레이어 추가·칠하기·실행 취소·저장·재편집, Z축 0, 관성 없는 회전, PSD 순서, 모바일·다크 테마 확인. 외부 Python·Node.js 없이 포터블 EXE 실행, CPU 분절, 독립 위젯 EXE 실행 확인.
