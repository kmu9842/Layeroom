Layeroom 1.1.0 — 레이어별 Z 위치 조절

- 각 레이어의 **Z** 버튼에서 슬라이더·숫자로 위치를 지정합니다. 앞면 0%부터 뒷면 100%까지 조절합니다.
- 한 레이어를 움직여도 다른 레이어 위치는 유지합니다. 조절을 마치면 목록도 실제 앞뒤 위치에 맞춰 정렬합니다.
- 전체 Z축 간격을 변경하면 개별 위치 비율을 유지합니다. 보조층과 그림자도 지정한 깊이에 맞춰 표시합니다.
- **Z 위치 균등 배치**, **원본 순서 복원**을 지원합니다. 드래그하면 현재 깊이 자리를 새 순서에 배정합니다.
- 저장·재열기와 내려받은 위젯에 개별 Z 위치를 반영합니다. 기존 작품과 PSD는 직접 변경하기 전까지 기존 순서를 유지합니다.
- 지정한 캐릭터를 사용한 실제 화면 가이드에 Z 위치 조절 설명을 추가했습니다.

`Layeroom-Windows-x64.zip`을 풀고 `Layeroom.exe`를 실행하세요. ZIP에는 EXE와 사용·사양 가이드 PNG 10장만 포함합니다. 컬렉션은 비어 있으며 모델·실행 환경·기존 작품·리서치 노트는 포함하지 않습니다. 필요한 구성요소는 첫 실행에서 선택 설치합니다.

기존 사용자는 트레이에서 종료한 뒤 같은 폴더의 EXE와 guide 폴더를 교체하세요. `_internal`과 `Layeroom.settings.json`은 유지하세요.

`Layeroom-Guides.zip`은 가이드 이미지 묶음이며, `Layeroom-Windows-x64.zip.sha256`으로 앱 ZIP을 확인할 수 있습니다.

검증: Python 53개, Z 위치 계산 3개, 페인팅 4개, 위젯 옵션 3개 통과. 브라우저에서 개별 위치·정렬·초기화·저장·모바일·다크 테마를 확인했고, 실제 위젯 EXE에서 저장하지 않은 변경값까지 반영되는 것을 검증했습니다. 배포 EXE의 첫 실행과 독립 실행 환경, 배포 파일 구성·SHA-256을 확인했습니다.
